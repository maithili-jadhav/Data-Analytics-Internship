# Week 3: Python & Data Wrangling

## Overview
This week focuses on cleaning and manipulating data using Python and Pandas.

## Tasks Completed
- Loaded and inspected a CSV dataset using Pandas.
- Checked and removed duplicate rows.
- Handled missing values.
- Converted columns to appropriate data types.
- Filtered rows based on conditions.
- Created new columns using existing data.
- Generated visualizations using Matplotlib and Seaborn.
- Calculated summary statistics.
- Exported the cleaned dataset to CSV.
