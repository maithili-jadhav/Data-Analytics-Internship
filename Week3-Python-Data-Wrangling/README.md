# Week 3: Python & Data Wrangling

## Objective

Clean and manipulate a dataset using Python and Pandas by handling missing values, removing duplicates, filtering rows, creating new columns, and performing basic data visualization.

## Tasks Completed

1. Loaded a CSV dataset into a Pandas DataFrame.
2. Inspected dataset structure, column names, data types, and basic information.
3. Checked for missing values and duplicate records.
4. Removed duplicate rows and handled missing values.
5. Converted columns to appropriate data types, including date conversion.
6. Filtered rows based on duration conditions.
7. Created new columns for calories per minute and pulse category.
8. Generated summary statistics using Pandas.
9. Visualized data using Matplotlib and Seaborn.
10. Exported the cleaned dataset to a CSV file.

## Key Findings

- Identified and handled missing values in the dataset.
- Removed duplicate records to improve data consistency.
- Explored duration and calorie distributions through histograms.
- Visualized the relationship between Pulse and Maxpulse.
- Created additional columns to support further analysis.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Learning Outcomes

- Gained practical experience in data cleaning using Pandas.
- Learned to handle missing values, duplicate records, and data types.
- Practiced filtering rows and creating new columns.
- Developed basic data visualization skills using Matplotlib and Seaborn.
- Learned to export processed data into CSV format.
