# Week 2: Python for Data Analysis

## Objective

Analyze sales data using Python and Pandas to clean, transform, summarize, and explore data.

## Tasks Completed

1. Loaded a CSV dataset into a Pandas DataFrame.
2. Inspected dataset structure, data types, and basic information.
3. Checked for missing values and duplicate records.
4. Cleaned and prepared the dataset for analysis.
5. Calculated total revenue by category.
6. Sorted data using multiple columns.
7. Generated a correlation matrix to explore relationships between numerical variables.
8. Exported cleaned and summarized data into CSV files.

## Key Findings

* Analyzed revenue across different product categories.
* Explored relationships between quantity, unit price, and total price.
* Prepared cleaned data for further analysis.

## Tools Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

## Project Files

* `week2_data_analysis.ipynb` — Analysis notebook
* `sales_dataset.csv` — Original dataset
* `cleaned_sales_dataset.csv` — Cleaned dataset
* `category_revenue.csv` — Revenue summary by category
* `sorted_sales.csv` — Sorted sales data
* `correlation_matrix.csv` — Correlation analysis results

## Learning Outcomes

* Gained practical experience in data manipulation using Pandas.
* Learned data inspection, cleaning, and validation techniques.
* Practiced grouping, aggregation, sorting, and correlation analysis.
* Improved skills in extracting insights from structured datasets.
