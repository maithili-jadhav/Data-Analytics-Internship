# Week 1: Excel & Data Fundamentals

## Objective

Analyze Global Superstore sales data using Microsoft Excel to understand sales performance, summarize business data, and create a dashboard using Pivot Tables and charts.

## Topics Covered

* Excel basics and navigation
* Excel formulas: SUM, AVERAGE, COUNT
* Data cleaning techniques
* Pivot Tables and data summarization
* Data types and descriptive statistics: Mean, Median, Mode, and Variance

## Tasks Completed

1. Analyzed Global Superstore sales data.
2. Summarized sales performance using Pivot Tables.
3. Calculated and presented total revenue.
4. Analyzed sales by category.
5. Visualized yearly sales trends.
6. Analyzed department-wise revenue.
7. Created a sales dashboard using charts and visualizations.
